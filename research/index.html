分层

隐私与复用分开

private

本机

具体持仓、成本、个人计划和未脱敏标的讨论；默认不进入 Git。

library

可复用

经过复核与脱敏的方法、经验和决策原则；可随代码版本管理。

data

证据

行情、指标、SQLite 历史库、快照和自动生成报告；不作为人工结论源。

私有研究暂不通过 Git 跨设备同步。需要同步时应使用加密备份，并继续排除凭证与个人敏感数据。
研究结论必须保留数据时间、来源和失效条件 查看系统能力
