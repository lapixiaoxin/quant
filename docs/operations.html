命令、服务与故障入口

日常操作只通过白名单 CLI 和两个独立 LaunchAgent；后台服务运行在 ~/.local/share/quant-monitor。 先观察状态和日志，再决定重启或重新安装。

核心命令

本地操作

./quant doctor

检查配置引用、策略、Skill 和外部 CLI。

./quant instruments

列出标的、策略画像、研究画像和通知策略。

./quant history --all

查看 SQLite 日线条数、日期范围和最近来源。

./quant strategies --symbol 515100

查看策略版本、生命周期和验证状态。

./quant select --universe ...

对版本化候选池执行硬门槛和市场指标初筛。

./quant backtest --strategy-record ...

使用本地历史回测冻结策略版本。

./quant analyze --symbol 515100 --no-send

运行标准周期与因子分析作业。

./quant prepare --symbol 515100

增量采集并生成 schema v4 数据包。

./quant daily --symbol 515100

生成确定性基础报告，不默认发送。

./quant automate --all

按 automation 配置运行 Agent 或基础降级。

./quant automate --all --no-send

不发送消息的完整链路验收。

./quant dashboard

刷新投资看板和根路径工作台。

./quant site

刷新五模块页面、内容目录和全局导航。

./quant listen --check

检查远程白名单配置和 lark-cli。

./scripts/sync_runtime_data.sh

暂停服务并把主写运行副本导出到私有仓库。

服务管理

LaunchAgent 操作

./scripts/service.sh status
./scripts/service.sh restart daily
./scripts/service.sh restart remote
./scripts/service.sh run-now daily
./scripts/service.sh stop all
./scripts/service.sh start all
修改 automation.enabled、remote.enabled、白名单或执行时间后， 重新运行 ./scripts/install_macos.sh，让 plist 与配置一致。

飞书入口

固定远程命令

/quant status

查看标的和自动化模式。

/quant strategies 515100

查看当前启用策略与验证状态。

/quant analyze 515100 daily,moving_average

执行标准分析并发送报告。

/quant analyze all daily

分析全部启用标的。

/quant base 515100

强制基础分析并发送。

/quant prepare 515100

只刷新数据包。

/quant dashboard

重新生成看板和根路径工作台。

/quant help

返回可用命令列表。

未授权发送人和群聊被静默忽略；未知命令不会转换为 Shell。

日志定位

四个常用文件

日志用途
运行目录/logs/daily.out.log定时任务执行结果和报告路径。
运行目录/logs/daily.err.log行情、Agent 或通知错误。
运行目录/logs/remote.out.log远程监听标准输出。
运行目录/logs/remote.err.loglark-cli 长连接和回复错误。

故障顺序

先诊断，再重启

  1. 运行 ./quant doctor

    确认配置、Skill 和 CLI 是否就绪。

  2. 运行不发送验收

    ./quant automate --symbol 515100 --no-send

  3. 检查对应错误日志

    区分行情失败、Agent 未登录、飞书权限或长连接问题。

  4. 重新安装服务

    配置发生变化时运行 ./scripts/install_macos.sh。

  5. 只重启故障服务

    使用 daily 或 remote 目标，不扩大影响范围。
