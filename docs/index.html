最快路径

部署到另一台 Mac

SSH 已具备仓库权限时，三条命令进入配置阶段。

git clone git@github.com:lapixiaoxin/quant.git "$HOME/Quant"
cd "$HOME/Quant"
./scripts/bootstrap_macos.sh --with-traecli --with-lark-cli
安装脚本不会覆盖已有的 config/config.toml，也不会在远程命令未完成白名单配置时启动监听服务。
