# 轻量研究架构

## 职责

Agent 主导问题定义、证据探索、假设、实验与解释。Python 内核提供可验证的数据、
指标、版本和执行模型。研究路径是“数据 → 分析 → 策略 → 回测 → 人工实战复盘”，
不是一条必须执行所有步骤的自动流水线。

模块化单体保留 `quant_monitor` 命名空间。`domain` 是纯计算，`application`
编排协议，`infrastructure` 适配行情、SQLite 与文件，`interfaces` 装配 CLI。
不引入 Agent 框架、Web 服务、消息系统或额外数据库。

## 数据与探索

`MonitoringService.prepare` 默认只采集、计算和保存 schema v5。
不解析启用策略目录，不把没有策略的标的视为配置错误。
行情通过 `MarketDataProvider` 转换为统一模型，日线仓储通过
`MarketHistoryRepository` 查询和幂等写入；首次与陈旧情况全量，通常使用
40 根重叠增量，保护原有非零质量字段并记录缺口修复。

`history --output` 从主库导出 CSV，供 Agent 使用 Python 或其他数据分析工具。
主库日线为前复权；原始不复权快照用于现金撮合。指标与未来预测分开，
Agent 必须检查时间、复权、来源与缺失状态。

## 策略与模型

配置画像保存算法和参数，策略目录保存稳定版本、生命周期、论点与模型绑定。
同标的多套策略独立评估，不无依据平均。`AnalysisService` 显式执行启用策略，
仅校验目标标的；指纹漂移或启用版本缺失时对应标的失败。

`draft/active/retired` 与 `pending/passed/failed` 分别表达生命周期和验证状态。
实验结果不会自动改变任何一个状态。探索假设无需先注册；正式复用后才进入目录。

可执行模型：

| 模型 | 数据 | 执行边界 |
|---|---|---|
| attention_score_allocation | 前复权日线与关注度策略 | 前日信号、次日开盘、比例成本 |
| dividend_yield_percentile_allocation | 日线和当时可得的真实股息率分位 | 缺估值拒绝；基本面门禁暂用指数规则代理 |
| cash_equity_swing | SHA256 冻结的不复权 CSV、分红、现金成本 | 整手、T+1、最低佣金、税费、限价穿透与双触保守处理 |

`backtest --strategy-record` 验证版本与画像指纹，输出完整 JSON。
`backtest --study` 按研究规格 v1/v2 选择有限网格比较或固定资金分账，
保留数据哈希、模型与代码哈希、训练/验证/留出、完整权益和成交。
规格变更创建新版本，不回写历史实验。现金撮合代码的现有语义不因外围精简变化。

历史回测尚不包含完整涨跌停排队、分钟路径、冲击成本和全部公司行动。
事后研究不能宣称严格样本外预测；平均仓位与成本必须参与结果解释。

## 文档与运行索引

飞书 Wiki 是人的阅读入口，根节点下每标的一篇主页，研究、策略与回测文档
作为其子节点。工程不内置飞书发布器，Agent 使用其可用飞书工具直接操作。
本地每版本只保留一份定稿及必要证据；scratch 中间稿不入库，目录按需建立。

`research/documents.json` 记录正文路径、关联来源及 SHA256、标的、策略、
模型、实验、时间、父节点与发布状态。`report-register` 通过文件锁串行更新，
本地正文或证据变化必须新建版本；`published` 要求链接和回读凭据匹配。
登记器拒绝引用 scratch 临时稿和 latest 可覆盖文件，校验本地凭据；
远端内容是否正确仍由 Agent 实际回读核验。

运行 SQLite 使用 schema v1，负责分析、筛选、回测和基础草稿索引。
旧通知字段仅作为历史列保留，新基础报告状态为 `draft`。
飞书发布索引单独记账，不伪装成旧消息推送状态；发布失败不丢弃本地正文。

`FileResearchRepository` 原子替换最新文件，行情/选择快照使用时间加随机唯一 ID，
基础草稿亦使用独立路径，避免同一时刻重跑覆盖。分析请求 ID 的内容固定。
批量分析保留各标的失败原因和成功文件，CLI 对部分失败返回非零。

## 工作区边界

- 移除前端工作台、页面生成、导航、看板与第三方 JS。
- 移除 `.trae`、`.traecli`、Agent 子进程、通知与飞书监听。
- 安装仅作用于当前工作区。旧后台服务需单独停用；不盲目同步运行目录数据库。
- 保留原始行情、可复用算法和回归样本；旧报告、策略草案、实验输出和迁移稿
  已清理，对应报告、策略与运行索引归零。新研究按需建立。
- 保留的正式实验包含完整证据和负面结果；未发布且放弃的探索可以整体删除，
  同步清理索引，检查共享引用。临时笔记、脚本和重复导出不长期维护。
- 旧本机通知/自动化段被忽略，配置秘密不改动。

数据契约见 `data/README.md`；发布协议见 `research/README.md`。
