研究

行情、策略与报告

ETF 行情与指标

已支持

双公开源降级，计算收益、均线、回撤、波动率和流动性。

产品与标的画像

已支持

产品默认、策略参数、研究重点和通知规则均可按标的覆盖。

确定性基础报告

已支持

不依赖大模型，适合作为每日可靠基线和 Agent 降级结果。

联网个性研究

条件支持

需要正确渠道的 TraeCode CLI、可用模型和非交互调用，按 schema v3 研究计划执行。

股票和指数专属策略

未支持

独立策略模块目录已就绪，尚未交付经过真实标的验证的实现。

回测基础契约

已支持

已定义版本、成本、滑点、长线信号和结果；撮合与样本外执行器尚未交付。

自动化

定时任务与飞书

能力状态条件与说明
工作日定时基础分析并推送 条件支持 启用 automation 和通知通道；无需 Agent。
工作日定时完整 Agent 研究 条件支持 还需 TraeCode CLI 模型可用并可非交互运行。
飞书出站报告 条件支持 需要飞书应用权限、密钥和接收目标。
飞书入站固定命令 条件支持 需要 lark-cli、长连接事件权限和白名单。
私有研究数据跨设备同步 已支持 主写设备导出运行副本；SQLite 必须按单写者流程交接。
飞书任意自然语言 Agent 未支持 当前只接受固定命令，避免扩大远程执行面。
自动交易 未支持 项目明确不提供券商下单或收益承诺。
