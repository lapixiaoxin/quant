Deployment

新设备自动化部署

以 macOS 为目标，完成项目安装、飞书出站、定时 Agent 研究和白名单远程命令。 后台运行副本位于 ~/.local/share/quant-monitor； 引导脚本会自动选择内场或公开版 CLI，人工环节主要是飞书后台和白名单确认。

部署步骤

从空设备到常驻服务

详细命令和故障处理以根目录 install.md 为准。

  1. 克隆并运行引导脚本

    git clone git@github.com:lapixiaoxin/quant.git "$HOME/Quant"
cd "$HOME/Quant"
./scripts/bootstrap_macos.sh --with-traecli --with-lark-cli

  2. 配置飞书出站与本机钥匙串

    在本机配置中设置 App ID 和接收目标；App Secret 存入 Keychain，不进入仓库。

  3. 验证 TraeCode CLI

    cd "$HOME/Quant"
~/.local/bin/traecli doctor
~/.local/bin/traecli models
~/.local/bin/traecli -p "只回复 OK"

    内场版复用企业凭据；公开版首次运行可能要求账号授权。定时任务使用非交互 -p 模式。

  4. 配置飞书长连接

    lark-cli config init --new

    飞书后台选择长连接，订阅 im.message.receive_v1，并开通机器人收信与发送权限。

  5. 确认发送人或群聊白名单

    先监听一条测试消息，获取 sender_id 或 chat_id，再启用 [remote]。

  6. 重装服务并验收

    ./scripts/install_macos.sh
./scripts/check.sh
./quant doctor
./quant history --all
./quant automate --all --no-send
./scripts/service.sh status

  7. 由主写设备同步研究数据

    ./scripts/sync_runtime_data.sh
git add data research
git commit -m "data: 同步研究数据"
git push origin main

    SQLite 不做 Git 自动合并。更换主写设备时先在旧设备导出并推送，再在新设备执行 QUANT_RUNTIME_DATA_MODE=replace ./scripts/install_macos.sh。
